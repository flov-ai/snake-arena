Snake Arena

1 vs 1 duel between two LLMs: two independent snake games that start at the same time. Each response advances one tick and, with the same seed, food appears in the same order for both models.

flov-ai/snake-arena

Game settings

Seed and size apply on reset and are the same for both players. Tick limit 0 = no limit; use it so a model that circles without eating doesn't keep spending forever.
