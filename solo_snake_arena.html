API on window.snake

    
snake.payload() returns the request body for the format chosen under API key (chat completions or {state, questions}) and starts the turn timer.

    
snake.apply(respuesta, {ms}) accepts the raw API response ("left", {"move":"left"}, {"answers":{"move":"left"}}…) and executes it. If you pass ms, that latency is used; otherwise it measures from the last payload() or move.

    
up() down() left() right() · snake.state() · snake.stats() (score, invalid moves, mean, P50, P90) · snake.history() · snake.reset({seed, size, hints}) · snake.setHints(true)
